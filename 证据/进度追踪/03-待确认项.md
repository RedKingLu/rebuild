## 2. 待确认项升级到决策记录的路径

```
1. 发现待确认项 → 登记到本文件
2. 判断是否需要升级为决策记录：
   - 影响范围/阶段边界/技术路线/安全红线/验收口径/长期事实源 → needs_decision=true
   - 阶段内执行口径 → needs_decision=false，登记到阶段报告/交接材料
3. Agent 给出事实、备选方案、推荐方案和理由，但不得自行标记 accepted
4. 用户裁决后：
   - 长期裁决 → 按 01-决策记录.md 追加规则生成决策草案
   - 阶段内执行口径 → 登记到对应阶段报告/交接材料/追踪表
   - 影响 AGENTS.md/Skill/R阶段总计划 → 按变更控制更新
5. 决策记录更新后，待确认项状态改为 promoted_to_decision 或 closed，反链决策编号
6. 禁止"口头确认但不回写追踪材料"
```
