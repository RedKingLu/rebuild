## 0. 状态口径

| 状态 | 含义 |
|------|------|
| `not_started` | 未开始 |
| `planned` | 已有计划或方案（方案文档已产出） |
| `in_progress` | 正在施工 |
| `partial` | 部分实现，仍有缺口（需写明缺口） |
| `implemented` | 已实现但未验收 |
| `verified` | 已通过测试/自验 |
| `accepted` | 用户/Copilot/独立验收按规则接受 |
| `blocked` | 被阻塞（需引用阻塞项ID） |
| `future` | 经明确理由归入未来（需引用决策/待确认项） |
| `deprecated` | 已废弃 |

**禁止将** `placeholder`、`mock`、`service 已写但页面未调用`、`API 存在但无真实状态` 标记为 `implemented`/`verified`/`accepted`。
