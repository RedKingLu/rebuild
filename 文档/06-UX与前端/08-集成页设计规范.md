## 1. 集成页定位

集成页是 rebuild 平台能力配置的关键入口，汇集执行器、编程 Agent、远程资源、Git 和基础设施接入点。

集成页回答：

```text
1.  当前平台接入了哪些 ExecutionProvider
2.  哪些编程 Agent 可用（含接入状态）
3.  哪些远程主机/Docker/SSH 已配置
4.  哪些 Git 仓库已连接，是否有待提交变更
5.  模型网关、文件系统等其他集成状态
6.  各集成的风险级别、权限边界和 Gate 要求
```

---

## 2. 页面总体结构

采用 KPI 卡片式子 tab 导航（5 个卡片，与 V26 Target Demo 验证模式一致）：

```text
┌─────────────────────────────────────────────────────────┐
│  页面标题 + 统计信息（启用/总数）                        │
│  ┌─────────┬─────────┬─────────┬─────────┬─────────┐    │
│  │ 执行器  │ 编程    │ 远程    │  Git    │ 其他    │    │
│  │ 接入    │ Agent   │ 资源    │         │ 集成    │    │
│  │         │ 接入    │         │         │         │    │
│  └─────────┴─────────┴─────────┴─────────┴─────────┘    │
│                                                         │
│  [当前子 tab 内容区]                                     │
└─────────────────────────────────────────────────────────┘
```

KPI 卡片字段：

```text
图标 + 标签
接入数量（启用/总数）
摘要说明
```

## 3. 子 tab 1：执行器接入

### 3.1 内容

ExecutionProvider 列表（Built-in / MCP / Wrapper），展示为小卡片网格。

### 3.2 卡片字段

```text
provider_id / provider_name / provider_type / status
risk_level / supported_environments / last_checked_at
gate_policy / trace_policy / audit_policy
真实能力标记（见 06-模型资源可视化与真实能力标记.md）
```

### 3.3 规则

```text
1. Built-in Executor 默认启用，但需标注能力边界
2. MCP 接入需标注"互操作协议，非安全边界"
3. 外部 ExecutionProvider 接入需展示风险等级（L0-L5）
4. 高风险 ExecutionProvider（L3+）标注"需 Gate + Audit"
5. 未接真实服务的 ExecutionProvider 必须标记 mock/not_connected（D-049）
6. 凭据密钥不回显
```

---

## 4. 子 tab 2：编程 Agent 接入

### 4.1 内容

外部编程 Agent 列表（如 QCode/OpenCode/Aider/Codex CLI），展示为小卡片 + 接入按钮。

### 4.2 卡片字段

```text
agent_name / agent_type / status / source
接入方式（Agent Wrapper / API / SDK）
risk_level / supported_stages / last_checked_at
```

### 4.3 规则

```text
1. 外部编程 Agent 经 Agent Wrapper 统一为 ExecutionRequest/Result
2. 禁止 auto approve——所有外部 Agent 输出需人审或 Gate
3. 未接入 Agent 标注"未接入"或"候选"
4. 参考性 Agent（如 Aider/Codex CLI）标注"仅参考，不作默认执行器"
5. 编辑策略借鉴来源需声明
```

---

## 5. 子 tab 3：远程资源

### 5.1 内容

远程主机/Docker/SSH 列表（对应 Environment Profile，D-051）。

### 5.2 卡片字段

```text
resource_id / name / resource_type（SSH/Docker/Remote Host）
addr（脱敏）/ status / environment_ref
risk_level / connection_status / last_checked_at
```

### 5.3 规则

```text
1. 远程资源地址需脱敏展示
2. 连接状态（已连接/断开/未配置）必须可见
3. 写盘/shell/外部执行需 Gate + 审计 + 回滚
4. 未接真实服务的远程资源必须标记（D-049）
5. 远程资源不自动成为当前项目默认环境——需在首次引导中声明（03 §25）
```

---

## 6. 子 tab 4：Git

### 6.1 内容

Git 仓库连接管理 + 当前更改预览 + 提交/推送操作。

### 6.2 左侧：已连接仓库卡片

```text
仓库名称 + 连接状态（已连接/断开）
仓库 URL（脱敏）
当前分支 / 账户（只读 + 受控写）
待提交变更数
```

### 6.3 右侧：更改与推送卡片

```text
变更文件列表（A/M/D 标签 + 文件路径）
提交信息输入框
提交按钮 + 推送按钮（受控）
```

### 6.4 规则

```text
1. Git URL 不得包含用户名密码或 token
2. 提交/推送为写操作：需 Gate 通过 + 人工确认 + 审计（D-034）
3. 高风险仓库操作（force push/branch delete）必须 L5 Gate（D-034）
4. 推送按钮在 Gate 未通过时 disabled
5. 变更列表展示文件路径 + 变更类型标签
6. GitHub 集成需展示连接账户（脱敏），repo 创建需 Token 权限
7. 未连接仓库时展示"接入 Git 仓库"引导入口
```

---

## 7. 子 tab 5：其他集成

### 7.1 内容

模型网关 / 文件系统 / 其他基础设施接入。

### 7.2 卡片字段

```text
integration_id / name / group / status / desc
```

### 7.3 规则

```text
1. 模型网关集成见 ModelGateway 规范（D-039）
2. 文件系统集成需标注读写权限边界
3. 未接真实服务的集成必须标记 mock/not_connected（D-049）
```

---

## 8. 联动

### 8.1 与 Gate 联动

```text
1. Git 提交/推送触发 Gate 时，Gate 横幅在 Workspace 中央展示
2. 远程资源高风险操作触发 Gate 时，跳转 Gate 检视
3. 执行器调用 Gate 通过 Gate/Authorization API
```

### 8.2 与 Trace/Audit 联动

```text
1. Git 操作（clone/commit/push）写入 Trace
2. 远程资源连接/断开写入 Audit
3. ExecutionProvider 调用写入 Trace + 高风险调用写入 Audit
4. 编程 Agent 调用写入 Trace
```

### 8.3 与 Evidence 联动

```text
1. Git 连接成功可作为 P0 接入 Evidence 候选（D-066）
2. 远程资源可用性可支撑 P4 执行阶段 Evidence
```

## 9. 安全与脱敏

```text
可展示：credential_status / credential_ref / redacted / repo_name / branch / source_type
不得展示：Git Token / GitHub Token / SSH Private Key / Password / 未脱敏连接串
```

---

## 10. Mock 与体验壳规则

R3 可先建设集成页体验壳，但必须显式标记 mock（D-049）。

```text
允许：静态 KPI 卡片 / 静态集成列表 / 静态 Git 仓库展示 / 静态远程资源列表
禁止：mock Git 操作显示为真实提交 / mock 远程资源显示为已连接可用 / mock ExecutionProvider 显示为真实可调用
```

## 12. 集成页红线

```text
1.  不得将集成页降级为设置子页面或资源子 tab
2.  不得展示 Git Token / GitHub Token / SSH Key / Password 明文
3.  不得将 Git 提交/推送显示为无需 Gate 和人工确认的普通操作（D-034）
4.  不得将远程资源默认显示为可用或已安全接入
5.  不得将 MCP 接入显示为安全边界
6.  不得将 mock 集成显示为真实能力（D-049）
7.  不得引入 Mission 产品层（D-070）
8.  不得使用旧 Phase/旧 F0-F6/旧 S0-S7 作为当前主流程
9.  不得在长期前端路由、组件、状态字段中固化 V26.1（D-002）
10. 不得把 R1 正式候选契约伪装为实现契约（D-016）
```
