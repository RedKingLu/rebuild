## 1. 文件面板定位

文件面板是 Project Workspace 左侧的导航与检索区域，用于帮助用户定位项目源码、产出代码、Patch、项目文档、产物、证据、运行记录和参考资料。

文件面板回答：

```text
1.  当前 Project Workspace 内有哪些源码文件
2.  哪些文件是产出代码或 Patch
3.  哪些材料是项目文档
4.  哪些材料是交接材料
5.  哪些材料是 Artifact
6.  哪些材料是 Evidence
7.  哪些材料是运行记录
8.  哪些材料只是参考资料
9.  哪些文件可编辑，哪些只读
10. 哪些材料存在 Evidence/Trace/Audit 关联
```

文件面板不是：

```text
1. 唯一状态源（D-053）
2. 阶段完成判断器
3. Evidence 验证器
4. Gate 决策器
5. 密钥查看器
6. 历史资料晋升器
```

> 关联决策：D-048（双视图）、D-053

## 2. 文件面板总体结构

R1 正式候选文件面板采用渐进实现策略：

```text
R3 初始（代码视图）：三根目录文件树
  — 产出物（只读）   — 产物文件，只读
  — 产出代码（可编辑） — 生成代码，可编辑
  — 源代码（只读）   — 原始项目源码，只读
  文件标记：EV（证据，蓝色）/ AR（产物，紫色）/ CH（变更，琥珀色）

R4/R8 扩展（材料视图）：六类材料身份
  — 项目文档 / 交接材料 / 产物 / 证据 / 运行记录 / 参考资料
  — 顶部添加视图切换（代码/材料），见下文 §4
```

顶部工具栏：

```text
视图切换（R4/R8 扩展后：代码/材料）、搜索、筛选
```

底部：

```text
当前选中对象摘要、状态标签、刷新入口
```

右键：

```text
打开、预览、编辑、定位引用、复制引用、查看 Trace
```

扩展筛选：

```text
按阶段（P0-P6）
按材料身份（6 类）
按状态
按来源
按是否只读
按是否有 Evidence Gap
按是否有 Trace/Audit
```

> 关联决策：D-048

```text
产物         — artifact
```

```text
3. 项目文档不等于 Artifact
4. Artifact 不等于 Evidence
5. Evidence 必须显示验证状态（D-066）
6. 运行记录不等于 Evidence
7. 参考资料默认只读
8. 历史参考资料不得自动成为当前事实源（D-004）
```

> 关联决策：D-004, D-048, D-066

## 5. 材料身份定义

材料身份 6 类（与 `03-ProjectWorkspace布局规范.md` §7 一致）：

```text
project_document   — 项目文档（长期事实源）
handoff_material   — 交接材料（协作区）
artifact           — 产物（Artifact）
evidence           — 证据（Evidence）
run_record         — 运行记录（Trace/Audit/Event/Run）
reference_material — 参考资料（只读参考）
```

展示标签建议：

```text
项目文档  |  交接  |  产物  |  证据  |  运行记录  |  只读参考
```

规则：

```text
1. 材料身份来自后端或 Workspace 元数据
2. 前端不得自行把 Artifact 晋升为项目文档
3. 前端不得自行把 Artifact 标记为 Evidence
4. 前端不得自行把 Evidence candidate 标记为 validated（D-066）
5. 身份冲突时应显示待校准/conflict，而不是自动选择一个
```

> 关联决策：D-066

```text
6. 项目文档不得包含密钥明文
```

## 12. 文件 / 材料打开行为

打开行为建议（与 `03-ProjectWorkspace布局规范.md` §8 类型单例 Tab 一致）：

```text
代码文件      → 打开文件编辑/预览 Tab
只读材料      → 打开预览 Tab
Artifact      → 打开 Artifact 预览 Tab
Evidence      → 打开 Evidence 详情 Tab
Trace/Audit   → 打开右侧检视或详情抽屉
Patch         → 打开 Diff/Patch Tab
Gate 相关材料 → 打开 Gate 检视
```

规则：

```text
1. 文件编辑和文件预览应区分
2. 只读材料不得进入编辑状态
3. Artifact 与 Evidence 打开后必须显示身份标签
4. 打开 Evidence 时必须显示验证状态
5. 打开敏感文件时必须先脱敏
6. 打开失败必须显示 error_ref / trace_ref
```

## 16. 与右侧检视联动

文件面板应与右侧检视联动（与 `03-ProjectWorkspace布局规范.md` §18 一致）。

联动规则：

```text
1. 选中 Artifact 时，右侧显示 Artifact 关联 Trace/Evidence 候选
2. 选中 Evidence 时，右侧显示 claim、validation_status、Evidence Gap
3. 选中运行记录时，右侧显示 Trace/Audit 摘要
4. 选中 Gate 相关材料时，右侧显示 Gate
5. 选中参考资料时，右侧显示来源、只读状态和引用注意事项
6. 联动仅刷新检视，不改变业务状态
```

## 18. 与 SSE / 事件联动

文件面板应响应后端事件。

建议事件（12 种）：

```text
workspace_status_changed
file_changed
artifact_created
artifact_status_changed
evidence_submitted
evidence_validated
evidence_gap_created
evidence_gap_resolved
trace_written
audit_written
run_status_changed
resync_required
```

规则：

```text
1. 事件不是唯一状态源
2. 事件只作为刷新提示
3. file_changed 后应刷新相关文件元数据
4. evidence_gap_created 后应显示缺口标记
5. resync_required 必须重新查询文件/材料树
6. 事件 payload 不得包含密钥
```

```text
刷新页面
重新进入 Workspace
SSE 断线重连
后台任务继续运行后返回
文件树加载失败后重试
```

恢复规则：

```text
1. 必须重新查询后端 Workspace/文件/材料元数据
2. 不得从浏览器缓存推断业务状态（D-053）
3. 不得从终端输出推断文件状态（D-053）
4. resync_required 必须触发全量刷新
5. 恢复失败必须展示错误
6. mock 恢复必须标记为 mock（D-049）
```

> 关联决策：D-049, D-053

## 20. 空状态与加载状态

空状态类型：

```text
无源码文件
无材料
无 Artifact
无 Evidence
无运行记录
无参考资料
未接真实 Workspace
加载失败
```

规则：

```text
1. 空状态不等于任务完成
2. 无 Evidence 不得显示为验证通过（D-066）
3. 未接真实 Workspace 必须标记（D-049）
4. 加载失败应显示 retry 和 error_ref
5. 空状态应提供下一步动作，但不得绕过 Gate/Policy
```

> 关联决策：D-049, D-066

## 21. 权限与只读策略

只读场景：

```text
历史参考资料
已归档材料
权限不足材料
Evidence validated 后受控材料
Audit 详情
敏感文件
社区只读资源
```

规则：

```text
1. read_only 必须可见
2. 只读材料不得出现编辑入口
3. 权限不足应显示权限原因或 error_ref
4. 审计材料详情可能需要更高权限
5. 只读不代表可公开
6. 前端不得通过本地状态解除只读
```

## 22. 密钥与敏感文件展示

敏感文件类型示例：

```text
.env / 配置文件 / 凭据文件 / 密钥文件
包含 token 的脚本
包含连接串的文件
内部日志
```

展示规则：

```text
1. 允许显示敏感文件是否存在
2. 允许显示 credential_status / redacted
3. 不得显示明文 Key/Token/Secret/Password
4. 不得显示可还原密钥片段
5. 不得在搜索结果中返回敏感内容
6. redaction_required 必须阻止展示原文
7. 截图、导出、报告不包含密钥
```

## 23. Mock 与体验壳规则

R3 可先建设文件面板体验壳，但必须显式标记 mock（D-049）。

允许：

```text
静态文件树 / 静态材料树
静态 Artifact / 静态 Evidence
静态 Trace/Audit 摘要 / 静态参考资料
静态搜索/筛选交互
```

禁止：

```text
1. mock 文件树显示为真实 Workspace
2. mock Artifact 显示为真实产物
3. mock Evidence 显示为 validated
4. mock Trace/Audit 显示为真实记录
5. mock 敏感文件显示为真实脱敏扫描结果
6. mock SSE 显示为真实事件
```

> 关联决策：D-049
