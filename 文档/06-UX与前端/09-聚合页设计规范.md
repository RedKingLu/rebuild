## 1. 聚合页定位

聚合页是 Fusion / SuperModel 聚合模型的独立管理入口，不绑定具体 Project，作为平台级模型增强能力。

聚合页回答：

```text
1.  当前有哪些聚合模型 Profile
2.  每个 Profile 的 Panel（多模型审议）、Judge（评判）、Synthesizer（综合）配置
3.  聚合在哪些阶段启用（P2/P3/P5）
4.  成本和延迟预算是多少
5.  当前是否已启用、最近一次触发结果
6.  聚合输出的增强证据如何进入 Artifact/Trace
```

## 2. 页面总体结构

两个子 tab（与 V26 Target Demo 验证模式一致）：

```text
┌─────────────────────────────────────────────────────────┐
│  页面标题："聚合" + 说明（默认关闭，模型增强能力）      │
│  ┌──────────────┬──────┐                                │
│  │ 聚合模型管理 │ 配置 │                                │
│  └──────────────┴──────┘                                │
│                                                         │
│  [当前子 tab 内容区]                                     │
└─────────────────────────────────────────────────────────┘
```

页面顶部提示：`Fusion 不阻塞基础 Flow；失败不影响主流程；输出作为增强证据进入 Artifact / Trace；不直接执行代码；不替代人工 Gate。`

---

## 3. 子 tab 1：聚合模型管理

### 3.1 内容

Fusion Profile 列表，展示为卡片（与 V26 Target Demo 验证模式一致）。

### 3.2 Profile 卡片字段

```text
profile_name / profile_id
enabled（启用/默认关闭）
Panel 模型列表
Judge 模型 / Synthesizer 模型
启用阶段（P2 / P3 / P5 标签）
成本上限 + 延迟上限
触发方式（手动触发 / 自动触发）
最近触发时间 + 结果状态
```

### 3.3 Profile 卡片操作

```text
启用/禁用开关
手动触发按钮
查看最近触发详情
```

### 3.4 规则

```text
1. 聚合默认关闭，需主动启用
2. 启用/禁用开关需确认（可能影响成本）
3. 手动触发后展示触发状态（queue / running / completed / failed）
4. 聚合失败时展示失败原因和 error_ref，不阻塞主流程
5. Profile 卡片不展示模型密钥
```

---

## 4. 子 tab 2：配置

### 4.1 内容

聚合策略配置，分为三个区域。

### 4.2 Panel（多模型审议）

```text
参与模型选择（多选）
审议角度（架构/安全/性能/可维护性等）
输出格式
```

### 4.3 Judge（评判）

```text
评判模型选择
评分维度 + 权重
置信度阈值
```

### 4.4 Synthesizer（综合）

```text
综合模型选择
输出模板
回写目标（Artifact / Trace / Evidence 候选）
```

### 4.5 全局配置

```text
风格：保守 / 平衡 / 激进
成本上限：≤ N × 单模型成本
超时时间
触发策略：手动触发 / P2 自动 / P3 自动 / P5 自动
审计级别：摘要 / 完整
```

### 4.6 规则

```text
1. Panel / Judge / Synthesizer 配置独立，可分别启用/禁用
2. 成本上限为硬约束，超限自动降级为单模型
3. 聚合配置不得绕过 Policy / Gate / Audit（D-035）
4. 配置变更写入 Audit
```

---

## 5. 聚合输出展示

聚合输出（Fusion 评估/方案审议结果）在相应阶段页中展示为"增强证据"（enhanced_evidence 标记），不自动成为 Evidence validated（D-066）。

输出展示：

```text
聚合 Profile 名称
触发阶段 / 触发时间
Panel 意见摘要（各模型观点对比）
Judge 评分 + 置信度
Synthesizer 综合建议
风险提示 + 限制声明
Trace 引用
```

---

## 6. 联动

### 6.1 与模型页联动

```text
1. 聚合使用的 Panel/Judge/Synthesizer 模型来自模型页配置的 ModelProfile
2. 模型不可用时聚合自动降级，提示"参与模型不可用"
```

### 6.2 与 Gate 联动

```text
1. 聚合输出不自动通过 Gate（D-035）
2. 聚合输出可作为 Gate 决策的参考材料
```

### 6.3 与 Evidence 联动

```text
1. 聚合输出标记为 enhanced_evidence，不自动成为 Evidence validated（D-066）
2. 聚合输出进入 Artifact + Trace
```

---

## 7. 安全与脱敏

```text
聚合模型密钥继承模型页配置，前端不回显
聚合输出中的敏感内容需脱敏
```

## 8. Mock 与体验壳规则

R3 可先建设聚合页体验壳，但必须显式标记 mock（D-049）。

