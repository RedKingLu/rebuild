## 1. 项目概览目标

项目概览页用于让用户快速理解一个 Project 当前处于什么状态、是否有后台任务、是否有阻塞、是否需要用户决策、是否有证据缺口。

项目概览应回答：

```text
1.  这个 Project 当前总体状态是什么
2.  当前处于 P0-P6 哪个阶段
3.  当前是否存在运行中的 Run
4.  是否有 Active Gate 需要用户决策
5.  是否有 Evidence 缺口
6.  最近产生了哪些 Artifact
7.  最近有哪些 Trace / Audit 记录
8.  Workspace 是否可进入
9.  后台任务是否仍在运行
10. 下一步推荐动作是什么
```

项目概览不应变成：

```text
1. 全量日志页
2. 全量文件浏览器
3. 单纯 Agent 对话页
4. 内部 R 阶段看板
5. 模型/资源配置页
6. mock 演示状态页
```

> 关联决策：D-003, D-009, D-023, D-052, D-066

## 2. 概览页布局建议

R1 正式候选 Project 概览页分为 10 区（与 `00-UX与前端总览.md` §6 一致）：

```text
1.  顶部项目摘要区
2.  当前 Run / 后台任务卡片
3.  P0-P6 阶段条
4.  Active Gate 卡片
5.  Evidence 缺口卡片
6.  最近 Artifact / Evidence 摘要
7.  Trace / Audit 摘要
8.  Workspace 入口
9.  下一步动作区
10. 事件 / 最近动态摘要
```

布局规则：

```text
1. Active Gate 和 Evidence 缺口优先级高于普通进度（D-023, D-066）
2. 后台任务状态必须可见（D-054）
3. Workspace 入口必须显示可用状态（D-050）
4. Trace / Audit 摘要只显示引用和摘要
5. mock 模块必须显式标记（D-049）
6. 不得因视觉简化隐藏风险
```

> 关联决策：D-023, D-049, D-050, D-054, D-066

## 4. 后台任务面板定位

后台任务面板用于展示 Project 内正在运行、暂停、阻塞、等待 Gate 或已完成的 Run / Import / Execution Session 等任务。

### 4.1 面板应出现的位置

```text
1. 平台概览页（00-UX与前端总览 §4）
2. Project 概览页（本文）
3. Project Workspace 顶部或底部（00-UX与前端总览 §8）
4. 全局任务入口
5. Gate / Error 详情关联处
```

### 4.2 面板不应

```text
1. 只存在于 Workspace 内
2. 只依赖浏览器当前会话
3. 因用户离开 Workspace 而消失（D-052）
4. 用终端输出来判断运行状态（D-053）
5. 用前端计时器伪造任务进度
```

> 关联决策：D-052, D-053


> 关联决策：D-023, D-054, D-070

## 6. 后台任务状态展示

后台任务状态（12 种）：

```text
created          — 已创建
ready            — 可启动
running          — 运行中
paused           — 已暂停
waiting_gate     — 等待 Gate
blocked          — 阻塞
rework_required  — 需要返工
failed           — 失败
canceling        — 取消中
canceled         — 已取消
completed        — 完成
archived         — 已归档
```

展示规则：

```text
1. running 任务应展示当前阶段和最近更新时间
2. waiting_gate 必须展示 Gate 入口（D-023）
3. blocked 必须展示阻塞原因
4. failed 必须展示 error_ref / trace_ref
5. rework_required 必须展示返工原因或返工计划引用
6. completed 不得由前端根据进度条推断
```

> 关联决策：D-023

## 7. 后台任务操作

后台任务面板建议操作（10 种）：

```text
查看详情
打开 Workspace
查看当前阶段
查看 Active Gate
暂停
取消
恢复
查看 Trace
查看 Audit
查看错误详情
```

操作规则：

```text
1. pause 不等于 cancel
2. cancel 是否需要 Gate 按风险和上下文判断（D-034）
3. resume 前必须校验 Gate、Policy、checkpoint、Workspace、Trace/Audit
4. Gate 未决策不得 resume 阻塞动作（D-023）
5. 前端按钮可 disabled，但权限事实必须来自后端
6. 高风险操作必须展示 Gate 或安全提示（D-034）
```

> 关联决策：D-023, D-034

```text

enabled

active_gate

```

展示规则：

```text
1. P0-P6 按固定顺序展示（D-009）
2. 被裁剪阶段显示 not_enabled / skipped / not_applicable，而不是 completed（D-009）
3. 当前阶段突出显示

5. Evidence 缺口必须在阶段条上可见（D-066）

7. P 阶段晋级必须用户 Gate（D-023）
```

> 关联决策：D-009, D-023, D-066

```text

4. L5 高风险动作必须明确提示"必须用户 Gate"（D-034）
5. Policy 禁止项不得显示为可批准
6. Gate 决策后应刷新 Run / Stage / Audit 状态
```

## 14. 下一步动作区

下一步动作区用于减少用户困惑。

建议动作类型：

```text
open_workspace        — 打开 Workspace
start_run             — 启动 Run
continue_run          — 继续 Run
handle_gate           — 处理 Gate
review_stage_plan     — 查看 Stage Plan
review_task_plan      — 查看 Task Plan
view_evidence_gap     — 查看 Evidence 缺口
view_artifacts        — 查看 Artifact
view_trace            — 查看 Trace
view_audit            — 查看 Audit
retry_import          — 重试接入
resume_run            — 恢复 Run
```

展示规则：

```text
1. next_actions 必须来自后端建议或前端基于后端状态的安全映射
2. Gate 未决策时，下一步应优先处理 Gate（D-023）
3. Evidence 缺口阻塞时，下一步应优先补证或查看缺口（D-066）
4. failed 状态应提供错误详情和可恢复动作
5. 前端不得建议绕过 Policy / Gate / Audit 的动作
```

> 关联决策：D-023, D-066

## 16. 状态恢复体验

状态恢复体验用于处理刷新页面、断线、离开 Workspace、重新登录或长时间后台运行后的状态同步（D-053）。

恢复入口：

```text
Project 概览页刷新
后台任务面板刷新
Workspace 重新进入
SSE 重连
Run 详情重新查询
```

恢复规则：

```text
1. 前端必须重新查询后端对象状态
2. 不能从终端输出推断任务状态（D-053）
3. 不能从浏览器缓存推断任务状态（D-053）
4. 不能从容器是否运行推断业务状态（D-053）
5. 状态恢复应结合后端数据库、checkpoint、workspace、trace/audit、event log（D-053）
6. 如果后端返回 resync_required，必须全量刷新相关对象
```

> 关联决策：D-053

## 17. 后台任务与 Workspace 退出

用户退出 Workspace 后，任务可能继续运行（D-052）。

前端必须表达：

```text
1. 退出 Workspace 不等于停止任务（D-052）
2. 任务是否继续取决于风险、Gate、Policy 和后端状态
3. 低/中风险且无需人工介入的任务可后台继续（D-052）
4. 遇 Gate、写盘、shell、外部系统写操作或高风险动作必须暂停（D-034, D-052）
5. 用户可从 Project 概览或后台任务面板重新进入
```

交互建议：

```text
退出 Workspace 时显示后台任务提示
如果有 active_gate，提示先处理 Gate
如果有运行中任务，提供"查看后台任务"
如果任务可继续，说明将继续在后台运行
如果任务暂停，说明暂停原因
```

> 关联决策：D-034, D-052

## 18. 错误与阻塞展示

项目概览页必须清晰展示错误和阻塞。

常见错误/阻塞：

```text
gate_required
gate_not_resolved
policy_blocked
evidence_missing
evidence_insufficient
trace_missing
audit_missing
checkpoint_missing
workspace_unavailable
resource_unavailable
model_unavailable
execution_failed
state_mismatch
internal_error
```

展示规则：

```text
1. gate_required 打开 Gate 视图
2. policy_blocked 不提示反复重试
3. evidence_missing 打开 Evidence 缺口
4. checkpoint_missing 不允许盲目恢复
5. workspace_unavailable 打开 Workspace 错误详情
6. 错误应显示 request_id / trace_ref，若后端提供
7. 错误详情不得包含密钥
```

## 19. 前端状态管理

项目概览和后台任务状态应分层管理（与 `00-UX与前端总览.md` §19 一致）：

```text
server_state        — Project、Run、Stage、Gate、Evidence、Trace、Audit、Workspace
realtime_hint_state — SSE/Event 的刷新提示
ui_state            — 展开、收起、选中 Tab、筛选项
draft_state         — 未提交操作
cache_state         — 可丢弃缓存
mock_state          — 显式标记的 mock 数据（D-049）
```

规则：

```text
1. server_state 必须可重新查询
2. realtime_hint_state 不得成为业务事实
3. ui_state 不得判断 completed（D-053）
4. cache_state 不得伪装为最新后端状态
5. mock_state 必须显式标记（D-049）
6. 前端不得自行推断 Run / Stage / Gate 状态（D-053）
```

> 关联决策：D-049, D-053

## 20. 安全与脱敏

项目概览和后台任务面板可能展示来源、执行输出、错误和 Trace/Audit 摘要，必须脱敏（AGENTS.md §12）。

可展示：

```text
credential_status
credential_ref
redacted
has_credential
last_checked_at
source_type
source_display_name
trace_ref
audit_ref
```

不得展示：

```text
Key
Token
Secret
Password
.env 明文
未脱敏连接串
可还原密钥片段
包含凭据的 Git URL
含敏感内容的终端输出片段
```

规则：

```text
1. 执行输出默认不展示敏感片段
2. 错误详情不包含凭据
3. Trace / Audit 详情按权限展示
4. redaction_required 必须阻止展示原文
5. 截图、导出、报告不包含密钥
```

## 21. Mock 与体验壳规则

R3 可先建设项目概览与后台任务体验壳，但必须显式标记 mock（D-049）。

允许：

```text
静态 Project 概览
静态 Run 卡片
静态 P0-P6 阶段条
静态 Gate 示例
静态 Evidence 缺口
静态 Trace / Audit 摘要
静态后台任务面板
```

禁止：

```text
1. mock Run 显示为真实运行
2. mock Gate 显示为真实授权
3. mock Evidence 显示为 validated
4. mock SSE 显示为真实事件
5. mock Workspace 状态显示为真实可用
6. mock completed 显示为真实完成
```

> 关联决策：D-049
