## 2. 状态模型总览

建议将运行时对象分为九组：

```text
A. 项目与流程对象：Project、Run、Stage、Stage Plan、Task Plan、TaskGraph、NodeLoop；
B. 代码与来源对象：Source Integration、Repository、Git Operation、Workspace；
C. 环境与执行对象：Environment Profile、Execution Session、Execution Command、Runtime Instance；
D. 资源调用对象：Resource、Resource Binding、Context Package、Invocation；
E. 变更对象：Patch、File Change、Diff、Commit；
F. 材料对象：Artifact、Evidence、Evidence Candidate、Evidence Gap；
G. 治理对象：Policy Check、Gate、Audit、Trace；
H. 输出对象：Output、Log、Error、Redaction；
I. 事件对象：Event、SSE Event、Resync Request。
```

基本关系：

```text
Project 是用户可见主对象；
Project 下可以有多个 Run；
Run 按启用的 P0-P6 Stage 推进；
Stage 内可有 Stage Plan、Task Plan、TaskGraph；
TaskGraph 由 Node 和 Edge 组成；
Node 内部执行 NodeLoop；
Workspace 归属 Project；
Environment Profile 归属 Project；
Execution Session 归属 Project / Run / Stage，可绑定 Workspace 与 Environment Profile；
Artifact / Evidence / Trace / Audit / Gate 均必须可回溯到 Project，通常也应回溯到 Run / Stage / Task / Invocation。
```

## 3. 通用字段约定

所有核心对象建议保留以下通用字段：

```text
id / *_id / *_ref：对象唯一标识；
project_id：所属 Project；
run_id：所属 Run，可为空；
stage：所属 P 阶段，可为空；
status：对象状态；
created_at：创建时间；
updated_at：更新时间；
created_by：创建主体；
updated_by：最后更新主体；
trace_refs：相关 Trace；
audit_refs：相关 Audit；
gate_ref / active_gate：当前 Gate；
error_ref：错误引用；
redaction_status：脱敏状态；
metadata：扩展信息，R2 校准。
```

规则：

```text
1. id 与 ref 的命名需在 R2 统一；
2. project_id 是多数对象的必备归属；
3. run_id 对项目级长期对象可为空；
4. stage 只能使用 P0-P6 或 null，不得使用旧 F0-F6 / S0-S7 / Phase；
5. metadata 不得成为隐藏事实源；
6. redaction_status 必须显式可见。
```

## 4. 通用状态枚举

### 4.1 生命周期状态

```text
created；
pending；
ready；
running；
paused；
completed；
failed；
blocked；
canceled；
closed；
archived；
unknown。
```

规则：

```text
1. completed 只代表当前对象动作完成，不代表上级阶段完成；
2. failed 不得自动重试为 completed；
3. blocked 必须说明阻塞原因；
4. unknown 不得默认 allowed 或 completed；
5. archived 不代表可作为当前版本事实源。
```

### 4.2 连接状态

```text
not_configured；
not_connected；
connecting；
connected；
reachable；
unreachable；
partially_available；
mock；
unknown。
```

规则：

```text
1. connected 不等于 verified；
2. reachable 不等于可用于验证；
3. mock 必须显式展示；
4. not_connected 不得显示为可用。
```

### 4.3 验收状态

```text
not_tested；
pass；
partial；
fail；
blocked；
needs_user_decision；
not_applicable。
```

规则：

```text
1. not_tested 不得写成 pass；
2. partial 不得写成 pass；
3. needs_user_decision 必须停下来确认；
4. not_applicable 必须说明裁剪或不适用原因。
```

### 4.4 材料身份状态

```text
reference；
draft；
candidate；
artifact_candidate；
evidence_candidate；
evidence_validated；
accepted；
rejected；
deprecated；
superseded。
```

规则：

```text
1. artifact_candidate 不自动成为 evidence_candidate；
2. evidence_candidate 不自动成为 evidence_validated；
3. accepted 必须有 Gate 或验收依据；
4. superseded 必须标明替代对象。
```

### 4.5 安全与授权状态

```text
allowed；
gate_required；
blocked；
redaction_required；
credential_required；
permission_limited；
policy_error；
unknown。
```

规则：

```text
1. blocked 不得继续；
2. policy_error 不得默认 allowed；
3. unknown 不得默认 allowed；
4. gate_required 必须暂停动作；
5. redaction_required 不得展示原文。
```
