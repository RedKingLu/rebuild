```text

2. Case 不是 Skill，也不是 Tool；

7. AST / codemod 等确定性转换能力以 Skill、Tool、Expert Agent 或 MCP 的资源形式接入；
8. 确定性转换器不得拥有特殊流程特权；
9. Tool / MCP / Expert Agent / 外部执行器均不得绕过 Policy / Gate / Audit；
10. 命令、Tool、MCP、写盘、Git 操作必须先映射风险级别；
11. L5 高风险动作暂定全部强制用户 Gate；
12. 密钥、Token、env 明文、私钥、连接串必须脱敏；
13. 外部执行器输出不自动成为当前事实；
14. Artifact 不自动成为 Evidence；
15. Evidence candidate 不自动成为 Evidence validated；
16. 当前版本不设独立 Mission 产品层。
```

> 上列含通用红线复述（如 P 阶段晋级 Gate、Policy 优先、Artifact 不自动晋升、L5 强制 Gate 等）——通用禁止与红线完整总表见 AGENTS.md §18，相关决策详见 01-决策记录.md，术语与风险级别（L0-L5）详见 02-术语表.md；L5 强制 Gate（D-034）/密钥脱敏（D-032）/不设 Mission（D-070）等安全红线就地保留。

本文不得：

```text
1. 将 Case 直接转为可执行脚本、Tool、Executable Skill 或 Patch；
2. 将外部执行器视为默认可信主体；
3. 将 OpenCode 或其他历史参考能力写成当前已实现事实；
4. 将 Tool / MCP / Expert Agent 输出写成 Evidence validated；
5. 将 Patch generated、Patch applied、命令 exit_code=0、构建成功、测试通过写成业务完成；
6. 将社区资源默认显示为可执行；
7. 将未登记资源用于真实执行；
8. 让资源绕过 Policy / Gate / Audit；
9. 泄露 Key / Token / Secret / Password；
10. 复活旧 RunEngine、旧 S0-S7、旧 F0-F6 或旧 Phase 主流程；
11. 把 R1 建议契约伪装为实现契约。
```

## 2. 资源分层

建议将平台运行期资源分为：

```text
Knowledge：只读知识材料；
Case：可检索、可引用、可比较的经验材料；
Skill：可被 Agent 采用的任务方法、流程约束或执行模板；
Tool：可调用工具，可能读、分析、转换、执行或写入；
MCP：以协议形式暴露资源、工具或上下文；
Expert Agent：具备专家能力的受控 Agent 资源；
External Executor：外部执行主体，如 OpenCode 或外部编程 Agent；
Deterministic Transformer：确定性转换器，如 AST / codemod / 规则转换；
Command Executor：本地或远程命令执行资源；
ModelGateway：模型调用与模型策略入口。
```

边界规则：

```text
1. Knowledge 默认只读；
2. Case 默认只读，不具备执行权；
3. Skill 约束 Agent 如何做事，不天然等于工具；
4. Tool 可以执行，但必须登记权限和风险；
5. MCP 可以暴露工具或资源，但不得绕过资源调用流程；
6. Expert Agent 建议不自动成为决策；
7. External Executor 不替代 LangGraph 主编排；
8. Deterministic Transformer 是资源，不是独立主线引擎；
9. Command Executor 必须受 Execution Session、Policy、Gate、Audit 约束；
10. ModelGateway 负责模型调用，不负责工具执行授权。
```

## 4. 资源身份

资源身份建议：

```text
built_in：平台内置资源；
local：本地资源；
online：在线资源；
community：社区资源；
archive_reference：历史归档参考；
project_specific：项目专属资源；
third_party：第三方资源；
unknown：来源未知。
```

资源执行身份建议：

```text
read_only_reference：只读参考；
candidate：候选资源；
source_verified：来源已核查；
accepted_for_adaptation：允许受控适配；
enabled：已启用；
disabled：已停用；
rejected：不采用；
deprecated：废弃；
blocked：被策略阻断。
```

规则：

```text
1. archive_reference 不得直接执行；
2. community 默认 read_only_reference；
3. candidate 不得显示为 enabled；
4. enabled 仍需按动作风险触发 Policy / Gate / Audit；
5. blocked 不得由 Agent 放行。
```

## 8. 风险分级

建议风险分级：

```text
L0：只读参考；
L1：只读读取项目文件、仓库状态或环境摘要；
L2：受控本地分析、生成候选输出、生成 Patch、生成报告；
L3：受控写盘、本地 Patch apply、本地命令执行、本地 Git commit；
L4：高影响写盘、依赖安装、环境修改、远程命令、远程执行、长时间任务；
L5：远端写操作、外部系统写操作、Git push、PR / MR 创建、远端分支删除、凭据重配、高风险权限升级。
```

> 风险级别完整定义见 `文档/00-项目治理/02-术语表.md` 第七部分和 `文档/07-安全与权限/02-风险分级与Gate策略.md`。

规则：

```text
1. unknown 风险不得默认 allowed；
2. L5 暂定全部强制用户 Gate；
3. 风险级别应由动作上下文决定，不硬编码命令清单；
4. 同一工具在不同动作中可有不同风险级别；
5. 风险接受必须写 Audit。
```

## 9. OpenCode 归口

OpenCode 在当前版本中归为：

```text
resource_type：opencode_adapter / external_coding_agent；
resource_identity：candidate 或 enabled；
source：archive_reference / local / third_party / unknown，按实际情况校准；
主要能力：read_file、analyze、generate_patch、write_file、run_command；
默认边界：受控外部执行器；
禁止身份：默认可信主体、主编排、P 阶段裁决者、Evidence 验证者。
```

规则：

```text
1. OpenCode 是否真实接入必须由 R6/R11 校准；
2. 未真实接入前只能标记 candidate / not_connected；
3. OpenCode 不得直接接收明文密钥；
4. OpenCode 输出不自动成为当前事实；
5. OpenCode 不替代 LangGraph 主编排；
6. OpenCode 相关历史材料只作参考，不自动成为当前实现事实。
```

## 10. Tool 归口

Tool 是可调用工具资源。

Tool 可包括：

```text
分析工具；
代码转换工具；
文件处理工具；
命令封装工具；
差异比较工具；
验证辅助工具；
报告生成工具；
外部服务适配工具。
```

Tool 规则：

```text
1. Tool 必须登记到 Resource Registry；
2. Tool 必须声明输入输出契约；
3. Tool 必须声明权限和风险；
4. Tool 调用必须写 Trace；
5. 高风险 Tool 调用必须 Gate / Audit；
6. Tool 输出不自动成为 Evidence validated；
7. Tool 输入不得含明文密钥。
```

> Tool 与 Case/Knowledge/MCP 的详细边界见 `文档/04-模型与资源/05-资源调用与Case-Knowledge-Tool-MCP边界.md`。

## 11. MCP 归口

MCP 资源可暴露工具、资源、上下文或执行能力。

MCP 规则：

```text
1. MCP 必须登记到 Resource Registry；
2. MCP Server 来源必须明确；
3. MCP 暴露能力必须逐项声明；
4. MCP 输入输出必须脱敏；
5. MCP 调用必须写 Trace；
6. MCP 高风险调用必须 Gate / Audit；
7. MCP 输出不自动成为 Evidence validated；
8. MCP 不得绕过平台 Policy。
```

## 12. Expert Agent 归口

Expert Agent 是专家能力资源，不是阶段裁决者。

Expert Agent 可用于：

```text
迁移方案建议；
技术栈分析；
风险识别；
验证策略建议；
执行计划建议；
代码修复建议；
差异解释。
```

Expert Agent 不得：

```text
1. 直接决定 P 阶段晋级；
2. 绕过用户 Gate；
3. 覆盖 Policy；
4. 直接写 Evidence validated；
5. 将建议冒充当前决策；
6. 接收明文密钥；
7. 替代独立验收 Agent。
```

## 13. 确定性转换器归口

确定性转换器包括：

```text
AST 转换；
codemod；
规则替换；
配置迁移；
依赖版本转换；
SQL / ORM 转换；
接口签名转换；
静态格式化和重写。
```

归口方式：

```text
Skill：描述使用方法和约束；
Tool：提供可调用转换能力；
Expert Agent：提供特定领域转换建议或审查；
MCP：以协议形式暴露转换能力。
```

> 确定性转换器的完整接入规范、Patch 流程和写盘授权见 `文档/04-模型与资源/06-确定性转换资源接入规范.md`。

规则：

```text
1. 不构建独立确定性转换主引擎作为主线；
2. 确定性转换器作为资源被 Agent 编排调用；
3. 转换前必须明确作用范围；
4. 转换输出应优先形成 Patch / diff；
5. Patch apply 必须按风险触发 Gate；
6. 转换结果必须进入 P5 验证；
7. 确定性转换器不得绕过 Policy / Gate / Audit。
```

## 14. Command Executor 归口

命令执行器包括：

```text
local_command_executor；
remote_command_executor；
managed_runner；
container_executor。
```

规则：

```text
1. 命令执行必须通过 Execution Session；
2. 命令必须映射 risk_level；
3. 高风险命令必须 Gate / Audit；
4. stdout / stderr 必须脱敏；
5. exit_code=0 不等于业务完成；
6. 命令输出不自动成为 Evidence validated；
7. 命令超时和失败必须可见。
```

## 15. 与 ModelGateway 的边界

ModelGateway 负责：

```text
模型调用；
Provider 适配；
模型策略；
模型选择；
token / 成本预算；
模型输出结构化。
```

外部执行器与工具资源负责：

```text
文件读取；
Patch 生成；
Patch apply；
命令执行；
构建；
测试；
运行；
外部资源调用；
确定性转换；
工具输出。
```

边界规则：

```text
1. ModelGateway 不执行写盘、命令或 Git 操作；
2. Tool / MCP / 外部执行器不负责模型 Provider 策略；
3. LLM 输出不自动授权 Tool 执行；
4. Tool 执行不自动证明 LLM 结论正确；
5. 二者都不得绕过 Policy / Gate / Audit。
```

## 16. 与 Agent / Skill 的边界

Agent 负责：

```text
理解任务；
组装上下文；
选择资源；
生成计划；
调用 Skill / Tool / MCP / Expert Agent；
自验证；
提交 Artifact / Evidence candidate；
处理失败升级。
```

Skill 负责：

```text
约束方法；
描述流程；
提供模板；
定义输入输出要求；
定义自验证清单。
```

资源负责：

```text
执行具体能力；
返回结构化输出；
记录 Trace；
遵守权限和风险策略。
```

规则：

```text
1. Skill 不天然等于 Tool；
2. Case 不得直接 Skill 化为可执行脚本；
3. Agent 不得绕过资源登记直接调用外部能力；
4. Agent 切换必须有条件触发；
5. Expert Agent 建议不自动成为决策。
```

---

## 17. 与 Workspace / Execution Session 的边界

规则：

```text
1. 资源读取和写入必须在受控 Workspace 范围内；
2. 外部执行器不得自行扩大 allowed_paths；
3. blocked_paths 永远优先；
4. 命令执行必须通过 Execution Session；
5. Execution Session 不等于长期事实源；
6. Workspace 状态必须后端可查询；
7. 容器、终端窗口或前端缓存不得作为事实源。
```

```text
14. 写 Trace；
15. 必要时写 Audit；
16. 生成 Artifact candidate 或 Evidence candidate；
17. 返回结构化结果；
18. 进入自验证或 P5 验证。
```
