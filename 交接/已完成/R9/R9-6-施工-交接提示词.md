3. **DB 路径**：`backend/app/core/database.py` 中有真实 SQLite 路径（`backend/.data/rebuild.db`）。G10 用独立 DB 时需设 `DATABASE_URL` 环境变量或 backend config。
4. **Gate decision API 路径**：`POST /api/projects/{project_id}/gates/{gate_id}/decision`（有 project_id 前缀），不是 `/api/gates/{id}/decision`（404）。
5. **Evidence 端点路径**：确认实际路径（可能是 `/api/projects/{id}/evidence` 或 `/api/evidence`，须读代码确认）。
6. **端口冲突**：8000 上可能有陈旧进程。测试用 8010/8020，验收完成后停掉。
7. **前端 dist/**：build 完才有；Playwright 需先 build 或用 dev server（确认 playwright.config 中 baseURL）。
8. **幂等键设计**：WP-3 的幂等键建议用 `(project_id, stage, status=active)` 查 active Gate/Run，不要用时间戳。
9. **WP-6 切图复杂性**：旧 routes_projects.py 的 execute 是 SSE 流，切图后需保持 SSE 格式对外兼容（或前端同步更新以接受新的图状态事件）。读 routes_graph.py 的现有 `/graph/start` 实现再设计。
10. **不要一次提交所有改动**：每 WP 独立 pytest 验证 + 记录落点后再进下一个；WP-8 再做 Git 提交（首次入库把 WP-1~7 全部打包）。
