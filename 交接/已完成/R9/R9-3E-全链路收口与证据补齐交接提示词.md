2. 保持不合格输入。

完成条件：Review Pass、返工、超限人工 Gate 均有可复现实证。

## 9. WP-E5：三模式自由切换与 Auto 授权边界补证

必须实测 Manual / Plan / Auto 三种模式的真实差异。

### 9.1 自由切换

验证：

1. Workspace 顶部切换 Manual → Plan → Auto。
2. 切换写 Trace。
3. 若授权密度变化，写 Audit 或有明确记录。
4. 刷新页面后当前模式仍可恢复。
5. 已执行动作的 effective_mode 不被回滚。
6. 切换仅影响后续动作。

### 9.2 Manual 模式

验证：

- 后续阶段内低风险动作也需要用户确认或明确提示。
- Review Pass 不被跳过。

### 9.3 Plan 模式

验证：

- 若已有阶段内计划，切换后提示沿用 / 重算 / 废弃。
- 计划内动作可自动执行，越界动作回用户确认。

### 9.4 Auto 模式

验证：

- L0-L3 阶段内动作可由 Auto 授权代理审核。
- Auto 授权输出结构化记录：decision、reason、risk_level、evidence_refs、trace_refs、audit_ref、mode、reviewer。
- Auto 不绕过 P0→P1 / P1→P2 阶段 Gate。
- Auto 不代理 L4+ 高风险动作。

完成条件：三模式不只是切换 API，而是对后续动作授权密度和流程有真实影响。
