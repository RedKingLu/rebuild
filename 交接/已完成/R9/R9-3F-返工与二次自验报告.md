## 1. 修复清单（对应 R9-4 §10 / §12）

### P0
1. **profiler SyntaxError**（`full_stack_profiler.py:517`）：嵌套 f-string 转义引号 → 预计算 `lang_dist/framework_str/build_str` 局部变量后再拼接。`import` 验证通过。
2. **stage_service uuid NameError**：`import uuid` 提到模块顶层；`promote()` 重写为定位本阶段 `waiting_decision` 的 stage_promotion Gate → 调用真实 `gate_service.decide()`，返回真实 `gate_status/audit_ref`。
3. **Gate 状态词表不一致**：`GateService.create()` 改为 `gate_status="waiting_decision"`，使 `get_active()` 与前端 GateBanner 能发现新建 Gate。
4. **coding-agents 500**：`routes_coding_agents.py` 7 个端点由 `db = get_db()`（误用生成器）改为 FastAPI `Depends(get_db)` 注入（会话随请求关闭，规避连接池泄漏）。
5. **Review Pass 未接线**：`ReviewPass`（execute→review→retry≤2→escalate）接入 `/profile`（review_fn 校验 14 项产物+P2 manifest+summary 落盘）与 `/onboarding/complete`（review_fn 校验 Run+intake_report）。失败则不创建晋级 Gate，诚实返回 escalation。
6. **Gate decide() 不闭环**：`decide()` 成为单一收口点——校验决策合法性（非法→ValueError→路由 400）；approve 推进 `current_stage`+run `stage_status`（completed/in_progress）并清 active_gate；reject→stage blocked；request_changes→stage changes_requested；全部写 Audit 并回填 `audit_ref`；`transition_mode="real"`。

### P1
7. **三模式行为差异 + Auto 授权代理**：新增 `app/services/mode_policy.py::authorize_action`，输出标准字段（decision/reason/risk_level/mode/reviewer/evidence_refs/trace_refs/audit_ref）。`/execute` 按模式授权：manual 需确认（`requires_confirmation`，不执行）、plan 低风险放行、auto 自动放行 L0-L3；**L4+ 任何模式都不自动代理**（deny-list 危险命令仍硬拦截）。
8. **模式持久化/回读**：前端新增 `fetchMode`，`WorkspacePage` 加载时从后端 `/mode` 回读 hydrate `execMode`，刷新后保持。
9. **materialization 诚实性**：`materialize()` 末尾不再用 `completed` 覆盖 per-type 设定的 `deferred`（git/github）/`empty`（manual）终态。
10. **进度追踪同步**：`04-施工记录.md`（REC-R9-01+统计表）、`01-功能表.md`（GAT-01/04 + 新增 PRJ-04/05/06）、`05-验收与证据索引.md`（EVD-R9-01）已更新。
11. **关键链路测试**：新增 `tests/test_r9_chain.py`（17 用例），覆盖 profiler 导入 / onboarding / gate 四态 / profile+P2 / Review 三路径 / 三模式 / materialization 诚实性 / coding-agents，杜绝绿色测试掩盖断链。

### P2（安全加固）
12. **ZIP zip-slip**：`create_project_with_zip` 改为逐成员 `zf.extract` + realpath 边界校验，越界成员跳过（不再依赖 `extractall` 隐式净化）。
13. **local_dir 敏感目录**：`SourceMaterializer._materialize_local` 拒绝 `/`,`/etc`,`/root`,`/var`,`/usr` 等系统根（含子路径），生成 Evidence Gap。

> 未做（诚实记录，归后续）：Gate/Run 的 DB 持久化（当前内存，重启失）；Plan 模式完整计划编排与 `effective_mode` 不可变历史；onboarding/profile 路由内若干 `try/except: pass` 仅做了关键路径加固，未全面替换；真实 git/github clone（deferred 待凭据）；真实 AI 编码 Agent 调用与 LangGraph 编排（graph_status 仍 mock 占位）。
