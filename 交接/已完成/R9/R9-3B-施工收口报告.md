### WP-B3 ✅：后端 onboarding completion 端点

**新建**：`POST /projects/{id}/onboarding/complete`（`routes_projects.py`）

请求体：
```json
{
  "execution_mode": "plan",
  "env_kind": "local",
  "language_hint": "Java",
  "framework_hint": "Spring Boot",
  "coding_agent_ref": "uuid-or-null"
}
```

执行动作（7 步）：
1. 更新 Environment Profile（PUT /environment）
2. 设置 Project.onboarding_done=true + coding_agent_ref
3. 创建 P0 Run（execution_mode 从请求写入）
4. 生成 intake_report Artifact → `artifacts/intake_report.json`
5. 生成 Evidence candidates（workspace_initialized + onboarding_completed）
6. 创建 P0→P1 promotion Gate
7. 写 Trace + Audit
