### 5.1 架构红线（不变）

- **D-066**：无 Evidence = 不可标记阶段完成。P2/P3 handler 均需收集并写入 Evidence。
- **D-082**：Acceptance 独立 Agent 实例，不共享执行 Agent 会话上下文。

### 5.2 R10 专项决策（Q-R10-* 裁决）

| 决策 | 内容 | 来源 |
|------|------|------|
| 分表持久化 | task_node（定义）与 task_node_run（运行实例）分表；利于版本链 + 多次运行 | Q-R10-1 |
| LLM 必须真实 | 无模型 Key = P2 blocked（不降级为规则评估）；适用 R10 全期 + 后续所有阶段 | Q-R10-2 |
| TaskGraph 必生 | P3 每次必生成 TaskGraph，禁止"无 TaskGraph + 理由"两路 | Q-R10-3 |
| P4 纯 stub | P4 handler 不注册，`future_r11` stub 保留；P3→P4 Gate 创建后 P4 不执行真实业务 | Q-R10-3 |
