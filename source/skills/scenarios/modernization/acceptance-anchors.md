# 软件现代化 —— 场景验收锚点

> 锚点须可判定：每条都要求指向真实执行产生的证据。

- 目标框架版本在产物中可验证：工程文件与构建输出中的目标框架标识为裁决的目标版本，有文件内容证据。
- 目标 SDK 上构建通过：使用目标运行时 SDK 真实构建成功，构建日志中的 SDK 版本与目标一致。
- 无残留旧配置文件：`Web.config` / `App.config` / `packages.config` 等旧格式文件已移除或明确说明保留原因。
- 旧 API 引用清零：`System.Web`、`AppDomain` 创建、`BinaryFormatter`、`javax.*` 等已知不可用 API 在产物中零引用，有检索结果证据。
- 依赖全部可解析：依赖还原在目标运行时上无缺失与无降级警告，有还原日志证据。
- 测试在目标运行时通过：测试套件在目标运行时上运行且通过数不低于改造前基线，有前后两次运行证据。
- 关键路径运行验证：应用在目标运行时上启动并通过关键路径冒烟，有运行日志证据。
- 异步改造无死锁：改造为 `async/await` 的路径中无 `.Result` / `.Wait()` 残留，有检索结果证据。
