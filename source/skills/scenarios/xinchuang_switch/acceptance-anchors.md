# 信创切换 —— 场景验收锚点

> 锚点须可判定：每条都要求指向真实执行产生的证据，不接受"已完成"式自述。

- 目标库连通性：应用以目标国产库的真实连接串完成连接与读写冒烟，有连接日志与冒烟结果。
- 对象迁移完整性：表 / 视图 / 序列 / 存储过程 / 触发器的迁移前后清点数一致，差异逐项有说明。
- 方言转换正确性：分页、空串与 `NULL`、大小写敏感、字符串拼接、日期函数的行为在目标库上有逐项比对结果。
- 数据一致性：分批迁移后有校验和或抽样比对结果，不以行数一致单独结论。
- 目标 OS 与 CPU 上真实构建：产物在目标 OS（麒麟 / 统信 / openEuler）与目标 CPU 架构上真实构建成功，构建日志中的架构标识与目标一致。
- 目标环境运行冒烟：服务在目标 OS 上启动并通过关键路径冒烟，有运行日志证据。
- 字符集验证：含中文的读写往返无乱码，排序结果与预期一致，有样本证据。
- 回滚预案可执行：切换方案含 expand-contract 或双写回退路径，且回退步骤已实测。
