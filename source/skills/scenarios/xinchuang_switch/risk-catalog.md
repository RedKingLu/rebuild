# 信创切换 —— 风险清单（具体不兼容点）

> 每条须是可验证的具体技术事实，不是泛泛套话。核实方式一并给出。

- 达梦 Oracle 兼容模式下 `ROWNUM` 分页与优化器 hint 语义与 Oracle 有差异 —— 核实：在目标库执行原分页 SQL 并比对结果集与执行计划。
- openGauss / KingbaseES 的标识符默认折叠为小写，而 Oracle 折叠为大写 —— 核实：以未加引号的混合大小写标识符建表并查询。
- PG 系中空串 `''` 与 `NULL` 不等价，Oracle 中空串即 `NULL` —— 核实：对可空列插入空串后用 `IS NULL` 查询比对。
- `MERGE` / `UPSERT` 语法与可用性在三个候选库间不一致 —— 核实：逐库执行原 `MERGE` 语句，记录是否需改写为 `INSERT ... ON CONFLICT`。
- GBK → UTF-8 迁移后中文排序结果随排序规则变化 —— 核实：对含中文的列做 `ORDER BY` 并与原库结果逐行比对。
- 达梦 / GaussDB 驱动的默认事务隔离级别与批量提交行为与原驱动不同 —— 核实：读取连接的实际隔离级别并压测批量写入的提交边界。
- LoongArch 与 aarch64 缺少部分上游原生依赖的预编译产物 —— 核实：在目标 CPU 上执行完整依赖安装与构建，记录需自行编译的依赖清单。
- 国产 OS 的 glibc / OpenSSL 版本与主流发行版不同，静态链接与预编译二进制常失效 —— 核实：在目标 OS 上运行产物并检查动态链接依赖解析结果。
- 容器镜像架构与目标 CPU 不匹配时会以模拟方式运行或直接失败 —— 核实：检查镜像 manifest 的架构标识并在目标机器上真实启动。
- `.NET Framework` 应用在国产 Linux OS 上无受支持运行时 —— 核实：确认是否已完成 `.NET 8/9` 跨平台迁移，未完成则国产 OS 落地不成立。
