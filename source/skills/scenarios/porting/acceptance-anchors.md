# 软件移植 —— 场景验收锚点

> 锚点须可判定：每条都要求指向真实执行产生的证据。移植的判据是行为等价，不是构建成功。

- 目标平台上真实构建：产物在目标 OS 与目标 CPU 架构上构建成功，构建日志中的平台与架构标识与目标一致。
- 目标平台上真实运行：应用在目标平台真机或真实虚拟机上启动并通过关键路径冒烟，有运行日志证据。
- 行为等价抽样比对：关键路径的输入输出样本集在源平台与目标平台各跑一遍且结果一致，有逐项比对结果。
- 条件编译已收敛：平台相关分支仅出现在适配层文件内，业务代码零条件编译，有检索结果证据。
- 原生依赖已重编译：全部含原生代码的依赖在目标架构上重新构建，有构建产物架构标识证据。
- 文件路径与大小写安全：路径拼接不含硬编码分隔符，资源路径大小写与磁盘一致，在区分大小写文件系统上验证通过。
- 本地化与字体验证：日期 / 数字格式与含中文的界面在目标平台上显示正确，有截图或样本证据。
- 符号与动态链接解析：产物在目标平台上无未解析符号，有动态链接检查结果证据。
