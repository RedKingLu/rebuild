# P-benchmark（性能基准与回归）

## 适用阶段与触发条件
P5 验证阶段，当迁移目标对性能有验收要求、或需在多个信创栈候选间做工程取舍（如达梦 vs GaussDB、东方通 vs 宝兰德）时触发。本 skill 是**工程性能基准**（latency/throughput/资源/构建耗时），非市场对标，非营销跑分。

## 输入
- 源系统（.NET/Java/Oracle/MSSQL）可访问的基线测量入口或历史性能数据
- 迁移后目标系统在信创栈（麒麟 OS + 国产 DB/中间件）的可测部署
- 关键业务场景与负载模型（典型查询、批处理、并发用户数、数据量）
- 验收性能指标与阈值（来自 P2 需求/SLA）

## 执行步骤
1. **定义负载与指标**：选取代表性业务场景，明确指标——响应延迟百分位（p50/p95/p99）、吞吐（TPS/QPS）、CPU/内存占用、构建/启动耗时。
2. **建源系统基线**：在迁移前于源系统采集上述指标，固定数据量与并发，多次运行取分布（非单次均值），记录环境快照（硬件、版本、配置）。
3. **迁移后复测**：在信创栈以**同等数据量、同等负载模型**复测，环境差异（ARM64 vs x86、国产 DB 参数）须显式记录，不可隐藏。
4. **栈间对比（可选）**：对候选栈（如同一负载下达梦 vs GaussDB）分别测量，统一口径对比，给出工程取舍依据。
5. **回归判定**：以百分位而非均值判定，关键指标劣化超阈值（如 p95 延迟 >10% 或吞吐下降 >10%）标记回归。
6. **归因**：对回归项定位（DB 执行计划、索引缺失、连接池、JIT 预热、字符集转换开销等），给出优化建议或风险说明。
7. **出报告**：汇总基线 vs 复测对比表、分布图、回归清单、归因与建议。

## 输出 / 产物（Artifact / Evidence）
- 性能基线数据集（源系统，含环境快照）
- 迁移后复测数据集（信创栈，含环境差异说明）
- 对比报告（百分位表、吞吐、资源、回归清单）
- 栈间对比结论（如有）
- 原始测量日志与运行参数（可复现）

## 质量门 / 验收标准
- 基线与复测使用同等数据量与负载模型，差异已记录
- 指标以百分位（p95/p99）呈现，每项至少多次运行取分布
- 回归项逐条有归因与处置（优化/接受/返工）
- 关键业务指标满足验收阈值，否则不得判 completed
- 测量可复现（参数、环境、脚本齐全）

## 场景要点（按项目场景取用）
- ARM64（鲲鹏/飞腾）与源系统 x86 在单核性能与 NUMA 行为上不同，对比须标注架构差异，避免误判为迁移缺陷。
- 国产 DB 执行计划与索引策略与 Oracle/MSSQL 不同，慢查询常源于计划退化而非硬件；归因须查执行计划。
- 字符集（GBK↔UTF-8）转换、达梦/openGauss 连接池与会话开销可能引入额外延迟，需纳入测量。
- on-prem 内网环境无弹性扩容，容量与峰值表现须以实际硬件为准。

## 反例 / 禁止
- 禁止只测迁移后不建源基线，导致无对照
- 禁止用单次测量或仅均值下结论（须分布/百分位）
- 禁止基线与复测负载/数据量不一致却直接对比
- 禁止隐藏环境差异（架构、版本、配置）粉饰结果
- 禁止把模型生成的预估数值当作实测 Evidence

## 与平台集成
- **能力接线（capability-first，R17.5-P5-R2）**：本维度已接线为平台能力——先用 `p5_verify_dimension` 探 `benchmark`（探测可测部署入口 / 远程执行主机是否绑定），或 `p5_dimension_capabilities` 看全量矩阵。**可测部署 + 环境就位** → 按上述步骤建源基线、复测、百分位对比产实测铁证；**缺失**（无可施压部署 / 无远程信创栈环境 / 无源基线入口）→ 该维度诚实标 `evidence_gap`（`capability_ready=true`，记"性能基准能力已接线，待可测部署/信创栈远程环境真验"），**非阻断、绝不把预估数值当实测**。能力/环境探测是确定性事实，工具不产"达标/通过"结论、不翻转 `can_be_completed`。
- 报告撰写若用模型辅助分析，调用经 ModelGateway；模型给出的归因/数值须有实测数据支撑，模型输出不等于 Evidence。
- 在生产/准生产环境施压测试属高风险（L4-L5），须经用户 Gate 并约定窗口。
- 基线、复测数据、对比报告、原始日志挂 Artifact/Evidence，测量动作记 Trace/Audit。
- 本 skill 产出的 Evidence 必须支撑明确的性能 claim；数据不足或未达阈值不得标记 completed，须回 P5 复测或返工。
